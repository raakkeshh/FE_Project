# FE_Project

Excited to share my latest project: Campus KL Sportz & Events Portal!

We recently built a responsive designed to streamline how students explore and register for campus activities. The goal was to create a unified platform that bridges the gap between student participation and administrative management.
Project Overview: The portal features a dual-login system catering to two distinct user roles.

Student Portal: Allows students to browse events (Tech, Sports, Cultural), filter by category, and manage their personal schedules. I also implemented a gamified "Points System" where students earn points for every event they join!

Admin Portal: A dashboard for organizers to track analytics, manage the event lifecycle (CRUD operations), and view a real-time student leaderboard.

Tech Stack & Key Features:
Frontend: Built with semantic HTML5 and modern CSS3. I used a "Dark Mode" aesthetic with neon accents for a modern, energetic feel.

Logic: Vanilla JavaScript handles all the state management. No frameworks were used, ensuring lightweight and fast performance.|

Data Persistence: Leveraged LocalStorage to simulate a database, allowing data (registrations and new events) to persist across sessions.

Analytics: Integrated Chart.js to visualize student participation trends dynamically.

Design: Fully responsive layout using CSS Grid and Flexbox, featuring a collapsible sidebar for mobile accessibility.

We really enjoyed working on the logic for the leaderboard and the dynamic event filtering. It was a great exercise in DOM manipulation and state management!
